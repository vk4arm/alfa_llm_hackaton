Kaspersky KUMA (SIEM)
Централизованный сбор и корреляция событий

Сбор неизменяемого WORM-аудита в формате CEF (Common Event Format) по Syslog TLS или Kafka. Корреляционные правила KUMA детектируют: взрывные серии джейлбрейков (ALFA_AI_001), аномальный дамп ПДн (ALFA_AI_002), аварийное размыкание Circuit Breaker (ALFA_AI_003) и искажение условий договоров (ALFA_AI_004).

Kaspersky Container Security (KCS)
Защита жизненного цикла Kubernetes

CI/CD сканирование образов Python 3.11 и vLLM на известные CVE до деплоя. KCS Runtime Sensor контролирует целостность рантайма, блокирует несанкционированные процессы, форсирует readOnlyRootFilesystem и защищает от выхода из контейнера (Container Escape) на GPU-ноды.

# Enterprise LLM Proxy (AI Gateway) для Крупного Банка 🏦⚡

Проект хакатона по созданию защищенного, высокопроизводительного и отказоустойчивого шлюза доступа к языковым моделям (семейство **Qwen 2.5**, **DeepSeek**, открытые LLM в закрытом контуре On-Premise).

## 🏛️ Интерактивный архитектурный портал (html/)
В папке `html/` разработан представительский портал архитектурных решений с глубоким инспектором компонентов:  
👉 **[html/index.html](html/index.html)**

### Что доступно на архитектурном портале:
1. **6 интерактивных архитектурных схем:**
   - **Топология сети и DMZ:** разделение клиентского контура, WAF-шлюза и изолированного On-Prem GPU-кластера vLLM.
   - **Sequence Flow (E2E):** сквозной конвейер обработки запроса (Аутентификация ➔ Vault ➔ Кэш ➔ Инференс ➔ NLI ➔ Restore).
   - **Circuit Breaker & Failover:** Hystrix-машина состояний и алгоритм каскадного переключения `Qwen-72B` ➔ `32B` ➔ `14B`.
   - **Двухуровневые Guardrails:** входные сверхбыстрые фильтры (<10 мс) + выходной NLI Cross-Encoder (`mDeBERTa-v3`).
   - **Zero-PII Vault (152-ФЗ / 395-1):** алгоритм Луна, паспорта РФ, Natasha Ru-NER и эфемерный Redis Session Vault.
   - **Fair Priority Queuing (QoS):** приоритизация очередей P0 (Realtime чат) / P1 / P2 с вытеснением фонового скоринга.
2. **Интерактивный инспектор узлов (Side Drawer):** клик по любому блоку схемы открывает панель с SLA, задержкой (Proxy Tax), оборудованием и стандартами ИБ.
3. **Мультирежимный вьювер:** мгновенное переключение между векторной SVG-схемой, кодом Mermaid.js и технической спецификацией.
4. **Интерактивный GPU-калькулятор сайзинга и TCO:** динамический расчет требуемых карт NVIDIA A100/H100, VRAM и годовой финансовой экономии банка (в млн ₽) от RPS, контекста и кэша.
5. **Сравнительная матрица бенчмарка:** фильтрация по категориям (Безопасность, Отказоустойчивость, Российский комплаенс) в сравнении с LiteLLM, Portkey и чистым vLLM.

4. **Тестер Zero-PII Vault и NLI-фактчекинга:** Живое распознавание и маскирование ПДн на лету и тест NLI-модели на противоречие фактам официального регламента.
5. **Нижний SIEM/Kafka терминал:** Потоковый вывод структурированных аудит-логов с таймстемпами и цветовой маркировкой.

## 🎯 Ключевые возможности решения

1. **Защита от перегрузок серверов инференса:**
   - **Circuit Breaker** (автоматическое обнаружение лагов и сбоев нод vLLM).
   - **Model Fallback Cascade** (бесшовный переход `Qwen-72B` ➔ `Qwen-32B` ➔ `Qwen-14B` ➔ Семантический кэш).
   - **Fair Priority Queuing & Backpressure** (приоритизация критичных каналов перед фоновым скорингом).
   - **Semantic Caching** (Redis + Vector DB, срез до 30% типовых FAQ-запросов).

2. **Безопасность и соответствие законодательству РФ (152-ФЗ, 395-1, ЦБ РФ):**
   - **Zero-PII Vault:** Обратимая токенизация на лету (карты по алгоритму Луна, паспорта РФ, СНИЛС, ФИО через NER). Персональные данные никогда не попадают в веса моделей и логи инференса.
   - **Ru-Guardrails (Цензура и токсичность):** Входной и выходной фильтр на базе `cointegrated/rubert-tiny-toxicity` (<10 мс) и базы RuJailbreak.

3. **Верификация фактов и анти-галлюцинации:**
   - **NLI Cross-Encoder** (`mDeBERTa-v3` / `RuBERT`) для проверки следования ответа исходному нормативному контексту (RAG Faithfulness).
   - **Числовой аудитор** (сверка ставок, дат, сумм с исходными регламентами банка).
   - **Guided Decoding / JSON Schema** для строгой структуры ответов.

## 🛠️ Программные микросервисы (`services/`) и DevOps (`devops/`)

Исходный код компонентов разбит на независимые микросервисы в папке `services/`:

```
├── devops/                      # Docker Compose, переменные окружения, оркестрация
│   ├── docker-compose.yml
│   ├── .env.example
│   └── README.md
└── services/
    ├── gateway-core/src/        # Основной API-шлюз с SSE-стримингом (FastAPI)
    ├── zero-pii-vault/src/      # Обезличивание по алгоритму Луна и Natasha NER
    ├── ru-guardrails/src/       # Детектор атак (Jailbreak) и токсичности (<10 мс)
    ├── resilience-router/src/   # Circuit Breaker и каскадный фоллбэк моделей
    ├── semantic-cache/src/      # Семантический векторный кэш (косинусное сходство)
    ├── nli-fact-guard/src/      # NLI Cross-Encoder и числовой фактчекинг регламентов
    └── audit-worm-logger/src/   # Неизменяемый WORM-аудит и экспорт метрик Prometheus
```

### Локальный запуск всего стека:
```bash
cd devops
cp .env.example .env
docker-compose up -d --build
```

# NLI Fact Guard (`nli-fact-guard`)

Модуль верификации фактов и защиты от галлюцинаций для банковских регламентов.

### Возможности:
- Оценка логического следования (Entailment / Neutral / Contradiction) между RAG-контекстом и ответом модели.
- Числовой аудитор: детекция искажения процентных ставок по кредитам, сумм и дат.
- Предотвращение юридических и финансовых рисков выдачи некорректных условий клиенту.

# Semantic Cache Engine (`semantic-cache`)

Движок семантического кэширования типовых запросов на базе векторного сходства.

### Возможности:
- Срез до 30–35% повторяющихся запросов контакт-центра и FAQ без обращения к GPU.
- Поиск по косинусной близости (порог > 0.95) с изоляцией по тенантам.
- Кэширование только очищенных от персональных данных (Zero-PII) векторов.

# Zero-PII Vault (`zero-pii-vault`)

Модуль обратимого обезличивания персональных данных и банковской тайны (152-ФЗ, 395-1).

### Возможности:
- Валидация и маскирование банковских карт по алгоритму Луна.
- Распознавание паспортов РФ, СНИЛС, телефонов и ФИО (Natasha NER).
- Эфемерное хранилище сопоставлений в Redis с TTL 300 секунд.
- Восстановление реальных данных перед передачей клиенту.

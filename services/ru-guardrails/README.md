# Ru-Guardrails (`ru-guardrails`)

Двухуровневый контур цензуры, безопасности и защиты от состязательных атак.

### Возможности:
- Детекция попыток обхода системного промпта (Jailbreak, DAN) на русском языке.
- Фильтрация токсичности, агрессии и ненормативной лексики с задержкой < 10 мс.
- Защита от утечки системных промптов (System Prompt Leakage) на выходе модели.

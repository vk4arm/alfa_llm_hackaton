# Gateway Core Service (`gateway-core`)

Основная точка входа шлюза искусственного интеллекта Альфа-Банка.

### Функции:
- Совместимый с OpenAI эндпоинт `/v1/chat/completions` со стримингом токенов (Server-Sent Events).
- Валидация JWT Keycloak и проверка заголовков `X-Bank-Tenant-ID`, `X-Bank-Priority`.
- Маршрутизация конвейера через модули безопасности, кэширования и отказоустойчивости.
